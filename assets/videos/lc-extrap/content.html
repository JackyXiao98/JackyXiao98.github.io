本系列的小实验（lcx）：两层 pre-LN 因果变换器（d = 64，4 个 16 维的头，MLP 256），Tiny Shakespeare 字符级语言建模（后 10% 作验证集）。位置方案五选一：可学习绝对位置（1,024 行的表，超出训练长度的行从未被训练）、正弦绝对位置、RoPE（底数 10,000）、ALiBi（四个头的斜率 1/2、1/4、1/8、1/16）、无位置编码。默认在长度 64 的片段上训练 2,000 步（批量 32，Adam 3e-3，余弦）。

视频中的实验（lcx.exp_extrap）

  • 五个模型在长度 64 上训练，在 64 个长度 512 的验证片段上评估每个位置的损失。平均（位置 32–63 / 64–79 / 80–127 / 128–510）：
  • 可学习绝对位置 1.74 / 3.83 / 3.85 / 3.82；正弦 1.70 / 3.49 / 3.80 / 4.03；RoPE 1.69 / 1.69 / 2.28 / 3.65；ALiBi 1.71 / 1.72 / 1.70 / 1.70；无位置编码 2.19 / 2.33 / 2.48 / 2.61。
  • 无位置编码的模型在训练长度内也明显较差，这与一些大模型上的报告（NoPE 在训练长度内可以接近其他方法）不同，可能是我们的模型太小、只有两层。单一随机种子。
