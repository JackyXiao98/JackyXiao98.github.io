本系列的小实验（sclx）：Tiny Shakespeare（约 111.5 万字符，65 种字符）字符级语言建模，后 10% 作验证集。模型为两层 pre-LN 因果变换器，宽度 d（每 16 维一个头，前馈宽度 4d），上下文 64 个字符；参数量 N 按 Kaplan 等人的约定只计非嵌入参数（每层 12 d²）；训练计算 C ≈ 6 N D，D 为训练过的字符数。默认 AdamW（无权重衰减），学习率 3e-3·sqrt(64/d)，100 步预热 + 余弦衰减，批量 32，梯度裁剪 1.0。

视频中的实验（sclx.exp_size）

  • 宽度 16 / 24 / 32 / 48 / 64 / 96 / 128（非嵌入参数 6,144 … 393,216），各训练 4,000 步（819 万个字符，约 8 遍训练集），验证损失（nats/字符）2.054 / 1.908 / 1.820 / 1.727 / 1.671 / 1.617 / 1.596；训练集损失 1.935 / 1.761 / 1.660 / 1.548 / 1.477 / 1.406 / 1.376。
  • 对数空间线性拟合：指数 α ≈ 0.061，参数每增加 10 倍损失乘以约 0.87。七个点并不完全在一条直线上：最大的两个模型的收益变小（过拟合，且固定 4,000 步对大模型训练不足）。
  • 单一随机种子；学习率按 sqrt(64/d) 缩放，未逐个调优。

参考

  • Kaplan et al. 2020：非嵌入参数的指数 α_N ≈ 0.076（约 10^5 – 10^9 参数）。
