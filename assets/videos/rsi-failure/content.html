视频中的模拟

  • 每代从上一代的正态分布抽 50 个样本重新拟合，200 次的中位数：标准差 0.98（第 0 代样本）→ 0.36（第 50 代）→ 0.14（第 100 代）→ 0.016（第 200 代）。\(|x|>2\) 的比例 4.6% → 第 50 代 < 1e−6。累积所有数据并保留真实样本：第 300 代仍为 0.97。
  • 真实质量 \(q\sim N(0,1)\)，代理奖励 = \(q\) + 误差，从 n 个候选中按奖励取最大，记录真实质量（每个 n 400 次）。高斯误差：n=4 时 0.70，n=16384 时 2.77；自由度为 2 的 t 分布误差：在 n=16 时最高（0.71），n=16384 时只有 0.06。
