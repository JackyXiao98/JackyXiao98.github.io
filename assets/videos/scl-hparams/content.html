本系列的小实验（sclx）：Tiny Shakespeare（约 111.5 万字符，65 种字符）字符级语言建模，后 10% 作验证集。模型为两层 pre-LN 因果变换器，宽度 d（每 16 维一个头，前馈宽度 4d），上下文 64 个字符；参数量 N 按 Kaplan 等人的约定只计非嵌入参数（每层 12 d²）；训练计算 C ≈ 6 N D，D 为训练过的字符数。默认 AdamW（无权重衰减），学习率 3e-3·sqrt(64/d)，100 步预热 + 余弦衰减，批量 32，梯度裁剪 1.0。

视频中的实验（sclx.exp_lr）

  • 宽度 32 / 64 / 128，峰值学习率 1e-3 / 3e-3 / 1e-2 / 3e-2，各训练 1,500 步（标准参数化，AdamW 无权重衰减，100 步预热 + 余弦）。
  • 验证损失：宽度 32：2.303 / 2.017 / 1.886 / 1.870；宽度 64：2.083 / 1.811 / 1.754 / 1.922；宽度 128：1.871 / 1.690 / 1.740 / 2.454。
  • 最好的学习率：0.03（扫描上限，真实最优可能更大）/ 0.01 / 0.003。只有四个格点、单一随机种子。
