本系列的小实验（sclx）：Tiny Shakespeare（约 111.5 万字符，65 种字符）字符级语言建模，后 10% 作验证集。模型为两层 pre-LN 因果变换器，宽度 d（每 16 维一个头，前馈宽度 4d），上下文 64 个字符；参数量 N 按 Kaplan 等人的约定只计非嵌入参数（每层 12 d²）；训练计算 C ≈ 6 N D，D 为训练过的字符数。默认 AdamW（无权重衰减），学习率 3e-3·sqrt(64/d)，100 步预热 + 余弦衰减，批量 32，梯度裁剪 1.0。

视频中的实验（sclx.exp_data）

  • 宽度 64（98,304 个非嵌入参数），训练集只取前 10k / 30k / 100k / 300k / 1,003,854 个字符，各训练 3,000 步（614 / 205 / 61 / 20 / 6 遍），每 150 步评估。
  • 最终验证损失 6.28 / 4.55 / 2.41 / 2.02 / 1.70；10k 时训练损失 0.14（几乎背下了训练文本）。
  • 训练过程中最好的验证损失（相当于在 150 步的粒度上提前停止）：2.82 / 2.50 / 2.27 / 2.02 / 1.70。
  • 单一随机种子；没有使用权重衰减或 dropout 等正则化，它们会减轻过拟合。
