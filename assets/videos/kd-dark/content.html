视频中的实验（kdx.dark_knowledge）

  • 老师同第 01 期。相似度表：老师在每一类测试图片上的平均 softmax（T = 4）。数字 3：3 → 86.9%，2 → 3.8%，9 → 2.8%，8 → 2.4%，4 → 0.0%。
  • 迁移集：去掉训练集里全部 117 张 3。学生 [64, 16, 10] 只学老师在剩余图片上的软标签（T = 4，不用真实标签）；对照学生只用硬标签。
  • 直接测试，3 的准确率（3 个种子）：软标签学生 0 / 23 / 3%，硬标签学生 0%。
  • 偏置修正：只调高 3 的 logit，直到约 10% 的（无标签）训练图片被判为 3。之后 3 的准确率：软标签学生 90.9 / 97.0 / 93.9%（平均 93.9%），硬标签学生 59.1 / 53.0 / 62.1%（平均 58.1%）。
  • 在全部训练图片上只用软标签（不用任何真实标签）：95.1 / 96.3 / 95.5%（平均 95.6%），老师 97.2%。

参考

  • Hinton et al., 2015，第 3 节：MNIST 上去掉所有 3 的迁移集；调高 3 的偏置后，学生正确识别了测试集中 98.6% 的 3。
