本系列的小实验（sclx）：Tiny Shakespeare（约 111.5 万字符，65 种字符）字符级语言建模，后 10% 作验证集。模型为两层 pre-LN 因果变换器，宽度 d（每 16 维一个头，前馈宽度 4d），上下文 64 个字符；参数量 N 按 Kaplan 等人的约定只计非嵌入参数（每层 12 d²）；训练计算 C ≈ 6 N D，D 为训练过的字符数。默认 AdamW（无权重衰减），学习率 3e-3·sqrt(64/d)，100 步预热 + 余弦衰减，批量 32，梯度裁剪 1.0。

视频中的实验（沿用 sclx.exp_size）

  • 只用宽度 16 – 64 的五个模型拟合，预测宽度 96 与 128（分别为拟合范围最大模型的 2.25 倍与 4 倍参数）。
  • 纯幂律（对数空间直线）：预测 1.561 / 1.496，实测 1.617 / 1.596，误差 −0.056 / −0.100。
  • L = E + A·N^(−α)，E 在 [0, 1.5] 上以 0.005 为步长网格搜索：E ≈ 1.39，α ≈ 0.31，预测 1.608 / 1.573，误差 −0.008 / −0.023。两种公式都偏乐观，与大模型的过拟合和训练不足一致。
