要点

  • 生成-验证差距：许多问题的检查比求解容易（数独、证明、带测试的代码）。最佳 n 选一（best-of-n）配合验证器，以及把选出的结果用于训练，是常见的自我改进方式。

视频中的实验（rsix.verifier_bestofn）

  • 加法 Transformer 训练到第 120 步（贪心解码准确率 28.5%），在 1,000 道测试题上按温度 1 采样，每题 32 次；单次采样正确率约 16%。
  • n = 1 / 2 / 4 / 8 / 16 / 32 时：完美检验 15.5 / 29.8 / 43.6 / 65.6 / 79.0 / 86.9%；只查个位数 15.5 / 27.2 / 35.9 / 45.2 / 49.3 / 51.0%；多数投票 15.5 / 18.5 / 19.3 / 23.7 / 24.6 / 26.2%。
