视频中的实验（mix.steering）

  • 进位方向 v = 第 1 层后、b 的个位处残差流：有进位题的平均 − 无进位题的平均（8,000 道训练题）；‖v‖ ≈ 6.5，该处残差流平均范数 ≈ 5.3。
  • 加到无进位的测试题上（α = 0 / 0.5 / 1 / 1.5 / 2）：十位 +1 的比例 0 / 24 / 75 / 80 / 80%，个位不变 100 / 95 / 79 / 75 / 74%。从有进位的题上减去：十位 −1 的比例 0 / 28 / 83 / 86 / 86%，个位不变 100 / 98 / 98.5 / 98 / 98%。
  • 示例：32 + 45，模型输出 077；加上 v（α = 1）后输出 087。
