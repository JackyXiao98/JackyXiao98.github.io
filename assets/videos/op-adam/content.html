视频中的实验（opx.optimizers）

  • Transformer 系列的加法模型（2 层，d = 64），批量 256，恒定学习率、无预热，600 步，每 20 步在 2,000 道测试题上算完全正确率。
  • SGD（η = 0.1 / 0.3 / 1 / 3）：最好 94.5%（η = 0.3），从未到 99%；η ≥ 1 时损失停在 ln 12 ≈ 2.485。
  • SGD + 动量 0.9（0.03 / 0.1 / 0.3 / 1）：最好 η = 0.03，第 500 步到 99%。
  • Adam（1e-3 / 3e-3 / 1e-2 / 3e-2）：η = 1e-3 与 3e-3 都在第 340 步到 99%；η ≥ 1e-2 训练失败。
