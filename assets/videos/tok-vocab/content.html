本系列的实验（tokx）全部从零实现：语料为 Tiny Shakespeare（Karpathy char-rnn，约 111.5 万字符，英文）与 chinese-poetry 项目《全唐诗》中的 4 个文件（poet.tang.0 / 1000 / 2000 / 3000，繁体中文，约 24 万字符）。预切分沿用 GPT-2 的思路：单词连同前面的空格作为一块，数字逐位分开，中文按标点切成最长 8 个字的片段。

视频中的实验（tokx.exp_vocab）

  • 同一个两层小变换器（d = 64，上下文 64 个词元，非嵌入参数 98,304）分别在字符（65）与 BPE 256 / 1,000 / 4,000 个片段的分词结果上训练 2,000 步（批量 32，Adam 3e-3，余弦），在后 10% 上评估。
  • 每个词元的损失（nats）：1.743 / 3.011 / 3.794 / 4.578；每个字符的词元数：1.00 / 0.55 / 0.43 / 0.34；每个字符的比特数：2.51 / 2.41 / 2.33 / 2.25。
  • 嵌入参数（输入 + 输出，2 × V × 64）：8,320 / 32,896 / 128,128 / 512,128；64 个词元覆盖的字符数：64 / 116 / 150 / 188。
  • 注意：步数相同时，大词表模型每步读过的文字更多、上下文覆盖的文字也更多，所以这是“同样计算量”而不是“同样数据量”的比较；小模型训练得也不充分，比特数远高于充分训练的模型。
