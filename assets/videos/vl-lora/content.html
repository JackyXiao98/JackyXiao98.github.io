本系列的小模型（vlx）：8 帧 16×16 彩色“精灵”视频（静态平滑纹理背景 + 一个方块 / 圆盘 / 十字，红 / 绿 / 蓝 / 黄，每帧移动 1 像素），4×4 像素一块、每帧 16 个词元；4 层空间 + 时间分解注意力的 DiT（d = 96，616,800 参数），flow matching 训练 6,000 步（批量 64），以（形状、颜色、运动）标签为条件，并有“干净词元”机制（首帧条件、掩码保留、参考词元）。它生成颜色可靠，但从噪声生成时对运动和形状标签的遵循较弱。

视频中的实验（vlx.rank_sweep）

  • 原模型只见过深色背景（生成的背景亮度 0.19）；新任务：浅色背景。原模型在 64 个浅色背景视频上的损失 2.757（深色背景 0.084）。
  • 所有注意力与 MLP 矩阵加 LoRA，Adam 1e-3，600 步，批量 32：秩 1 / 2 / 4 / 8 / 16 → 损失 0.238 / 0.219 / 0.203 / 0.185 / 0.181（参数 8,448 / 16,896 / 33,792 / 67,584 / 135,168）；全量微调（Adam 2e-4）0.167。所有 LoRA 生成的背景亮度约 0.84。
  • 全量微调改变量 ΔW 的奇异值能量：最大的 1 个方向平均占 27%，前 8 个占 76%（24 个矩阵平均）。
