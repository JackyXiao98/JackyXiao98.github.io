本系列的小实验（moex）：数据来自 8 种隐藏的“语言”，词表 32，每种语言是一条一阶马尔可夫链（各自的随机尖锐转移矩阵）；每段序列长 32，来自其中一种，模型需要从上下文推断语言再预测下一个词元。最好可能的损失是给定语言时的真实条件熵 ≈ 1.557。模型是两层因果变换器（d = 64，4 头），只改前馈层：稠密（宽度 h）或混合专家（E 个宽度 he 的专家，top-k 路由）。默认训练 2,000 步，批量 32，Adam 3e-3（100 步预热 + 余弦衰减），在 256 段留出序列上评估。专家用“稠密计算再掩码”的方式实现，只适合玩具规模。

视频中的实验（moex.exp_capacity）

第一期平衡好的模型（8 × 128，选 1，辅助损失 0.01）。每批的专家容量 \( C=\lceil \mathrm{cf}\cdot N k / E \rceil \)，按词元在批中的顺序先到先得，超出的词元跳过专家、只走残差。训练（每步 N = 1,024）和评估（N = 8,192）都施加容量限制。

  • cf = 0.5 / 1.0 / 1.25 / 2.0：训练结束时丢掉 50.0% / 4.1% / 0.2% / 0% 的词元，损失 1.969 / 1.735 / 1.715 / 1.701；不限容量 1.686。
  • 第 0 步（路由尚未均衡）：丢弃 65% / 45% / 38% / 26%；cf = 2.0 在第 100 步之后几乎不再丢弃。
  • cf = 2.0 与不限容量之间 0.015 的差距只来自一次运行（单一随机种子），我们不把它当作结论。
