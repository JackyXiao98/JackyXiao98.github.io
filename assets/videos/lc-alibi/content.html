本系列的小实验（lcx）：两层 pre-LN 因果变换器（d = 64，4 个 16 维的头，MLP 256），Tiny Shakespeare 字符级语言建模（后 10% 作验证集）。位置方案五选一：可学习绝对位置（1,024 行的表，超出训练长度的行从未被训练）、正弦绝对位置、RoPE（底数 10,000）、ALiBi（四个头的斜率 1/2、1/4、1/8、1/16）、无位置编码。默认在长度 64 的片段上训练 2,000 步（批量 32，Adam 3e-3，余弦）。

视频中的实验

  • ALiBi 偏置：四个头的斜率 1/2、1/4、1/8、1/16；距离 500 时最平缓的头偏置为 −31。
  • 第三期（lcx.exp_extrap）：位置 128–510 的平均损失，RoPE 3.65，ALiBi 1.70。
  • 检索任务（lcx.exp_needle）：16 种随机干扰词元中藏一个（标记, 键, 值）三元组（8 种键、8 种值），末尾给出（查询标记, 键），预测值。RoPE / ALiBi / 无位置编码各在长度 128、深度均匀随机的数据上训练 1,500 步。测试 256 条序列，深度 0 / 0.25 / 0.5 / 0.75 / 1（0 = 离查询最远）：
  • 长度 128：三者都在 98.8%–100%。长度 512：RoPE 90.6% / 73.0% / 89.5% / 100% / 100%；ALiBi 74.2% / 80.9% / 86.7% / 100% / 99.2%；无位置编码 100% / 100% / 100% / 100% / 97.7%。
  • 无位置编码的模型在这个检索任务上外推最好，与 Kazemnejad et al. 2023 的发现一致；但第三期中它的语言建模损失最差。单一随机种子。
