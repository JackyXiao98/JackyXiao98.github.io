视频中的实验（kdx.fitnets）

  • 学生 [64, 32, 32, 10]，只有 100 张带标签的图片，另外可以使用全部 1,197 张训练图片的输入（无标签）。3 个种子，3,000 步。
  • 只用标签：87.4 / 86.3 / 86.4%（平均 86.7%）。
  • + 提示损失（λ = 1）：学生第 2 个隐藏层经可学习的 32 → 512 线性映射，对齐老师第 1 个隐藏层，在全部输入上计算：87.6 / 87.9 / 88.4%（平均 88.0%，+1.3 个百分点）。
  • 老师在全部输入上的软标签（不用真实标签）：96.0 / 96.0 / 96.6%（平均 96.2%）。
  • 在探索中，单独的提示预训练（两阶段）和更深更窄的学生都没有带来提升；这里报告的是联合训练的结果。
